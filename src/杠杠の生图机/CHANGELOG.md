# Changelog

本文件记录 `杠杠の生图机` 的用户可感知变化。版本以脚本专属 Git 标签为准，不跟随多脚本仓库根版本。

## [Unreleased]

## [0.3.0] - 2026-09-04

### Added

- 新增可新建、保存、修改和删除的画图预设，只负责正文 AI 指令。
- 新增独立的出图预设，使用 `{{xx}}` 接入解析结果，并可选择 User 图 1、角色图 2 作为参考图。
- 最近生成数量可由用户设置为 1–50 张，默认 10 张；每张图片可删除或保存到角色图库。
- 新增统一展现设置：正文插图或礼物异步，以及 `skipFloors` 楼层频率。
- 图片列表新增显式“保存到角色图库”。

### Changed

- 随文图与礼物图合并为统一 `{ prompt, referenceImages? }` 请求流水线。
- 出图模板始终应用；关闭头像参考时完全跳过头像读取并省略 `referenceImages`。
- 楼层计数只接受新 `normal` assistant 回复；第 1 楼先触发，之后隔 N 楼。
- 旧随文和礼物文字配置迁移为默认预设与 v0.2 兼容预设。

### Removed

- 移除手工三参考图、独立礼物任务、3/5 楼旧调度和未接入的预测槽。
- 移除浏览器下载、复用到最新回复、撤回复用和配文编辑；图片只可由用户显式保存到角色图库。
- 最近图片池改为普通 FIFO，不再保留或固定单张图片。

### Fixed

- 随文图片请求期间恢复在正文对应位置显示“正在生图…”，成功后由图片替换，失败或任务失效时自动清理。

## [0.2.0] - 2026-08-24

### Added

- 新增礼物 CG：可手动生成，或每 3 / 5 条新 AI 回复自动尝试一次。
- 新增三张页面内参考图槽，用于角色 1、角色 2 与双人姿势参考。
- 新增最近生成列表，最多保留 5 张图片，可下载、复用到最新 AI 回复，并可附加一句短配文。
- 新增“撤回上一次复用”，只撤销本页最近一次 placement。
- 随文插图与礼物 CG 可以分别选择 API 配置档案。
- 礼物 CG 成功进入最近生成后显示一次到达提示。
- 新增 `window.__storyImageAudit` 的礼物、最近缓存、复用和到达通知证据。

### Changed

- 每个图片任务只发送一次请求；失败后不自动重试，也不会阻塞聊天正文。
- 自动礼物条件不足、已有任务或请求失败时直接跳过，不排队、不补跑。
- 最近生成池保持在 5 张，以限制当前页面的内存占用。
- 图片、参考图、最近生成、placement 和任务状态统一保持为当前页面内存，不恢复历史楼层图片。
- 图生图的请求形态由显式 API 模式决定；升级后若服务依赖 JSON 参考图，需要明确选择对应模式并核对字段名。

### Fixed

- 关闭随文生图总开关后，不再扫描、清理或回写消息正文中的控制标签。
- 官方 OpenAI multipart 编辑请求改用重复的 image[] 与 Bearer 认证；自定义中转继续保留可显式选择字段及原有双认证头兼容。

- 旧 generation、旧聊天、旧 swipe 或已失效任务的迟到结果不再覆盖当前图片状态。
- 较早开始的参考图读取不会覆盖更新选择，也不会在用户清空后重新出现。
- 多张随文图在楼层重绘和 swipe 切换时保持正确段落、顺序与 swipe 归属。
- 最近池淘汰、复用撤回、图片加载失败和生命周期清理会释放对应页面资源。
- 到达通知失败不会污染已经成功的礼物 CG 状态。

## [0.1.0] - 2026-08-23

### Added

- 首个脚本专属公开版本。
- 支持根据正文控制标记异步生成并显示最多两张随文插图。
- 图片任务按聊天、消息、swipe 和图片序号隔离，不把生成图片写入聊天正文或持久存储。
