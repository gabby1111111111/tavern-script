## Step 1：配图资格与上一镜头开关

- 剧情位置的资格不因 Swipe、删除尾回复后重建或 regenerate 丢失；这些替换不重复推进间隔，真正新推进才计数。取消不消耗计数，切聊天/重载仍清空页面状态。
- Swipe 新回答仍受其独立开关控制；仅查看旧 Swipe 不请求图片。被删除回答的图片与任务清理，不因数字楼层号复用而继承。
- 关闭上一镜头开关时，不发送上一图，画图和出图预设的 `{{xx_pic}}` 都为文字 `null`；头像独立。开关开启时只取有效已确认来源。
- Codex 验收：资格 ledger、runtime-policy、模板和请求回归，涵盖重复事件、删除重建、regenerate、Swipe 开关、取消、空值与非递归替换。
- 运行时审计验收：真实酒馆版本及生成入口证据，核对请求次数、资格原因、来源状态和提示注入；无付费请求的拦截测试与真正 API 出图须分开记录。
- 人工验收：设置文案是否易懂，无需用户判断事件时序。

## Step 2：异步修图与悬浮面板

- 生成结果作为未确认底图；重绘结果是待选版本，不自动采用为底图或后续参考。浏览与确认分开。
- 用户继续聊天时留住旧镜头底图；首次推进可清理此前未选中的旧候选，但不因随后每次聊天推进清掉异步新增待选版本。
- 确认只清理该镜头的其他版本；放弃整个镜头取消其任务并清理所有版本，迟到结果不得复活。B、C 同时待确认互不清理。
- 下一次配图按剧情顺序选当前预设组合最近的已确认镜头；B 未确认则用 A，无库存则不附上一图。提醒不阻塞、不附带操作要求；快照锁定后不因后来确认 B 自动重跑 C。
- 悬浮面板显示当前聊天有效 Swipe 镜头、`{{xx}}`、来源楼层、状态和候选；可预览、重绘、确认、删除候选、放弃镜头和回到原楼层。
- Codex 验收：状态机、候选/底图选择、异步与迟到结果、确认/放弃、有效 Swipe 和删除校正；目标 ESLint、相关测试及生产构建。
- 运行时审计验收：加载唯一悬浮入口、关闭/重开/卸载清理、正文与面板动作一致、受控测试中的请求次数及作用范围；审计不得记录图片 URL、Base64 或提示词正文。
- 人工验收：面板位置、移动端可用性、边聊边修是否顺手、参考确认是否容易理解。
