# 杠杠の生图机 v0.4.0

## 安装

使用固定标签加载：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.4.0/dist/杠杠の生图机/index.js';
```

## 新增与改进

- 按“画图预设＋出图预设”组合延续连续剧情，参考前面楼层当前显示的有效正文插图。
- 支持 `{{xx_pic}}` 上一镜头文字和 `{{reference_sources}}` 实际来源编号。
- 头像参考与上一镜头图参考可以独立选择，来源不可用时会跳过并重新编号。
- 修改图片提示词时直接编辑最终 API 文本；文本会在页面内存中保留，清空后禁止空提交。
- 区域重绘默认无需画笔，只使用当前图和修改描述；需要局部引导时再打开画笔模式。
- 参考读取取消、缓存淘汰和编辑器重复开关等边界状态已补齐收束处理。

## 验证范围

- 已验证真实酒馆的正文事件修复和一次普通生图成功。
- 连续引用上一图的完整请求与视觉效果、本次新增编辑器交互及无需画笔重绘，尚未完成真实环境验收；本版不宣称这些路径已全部验证通过。

## 已知限制

- 图片和编辑内容只保存在当前页面内存；刷新、重载或切换聊天后不会恢复历史图片。
- 参考图的具体请求形式由 API 配置和服务端能力决定。头像、上一镜头图、不同 API 模式、inline、gift、区域重绘和图库保存仍应在实际 SillyTavern 中分别验证。
- 参考图用于保持视觉元素，不承诺像素级一致；人物识别度和视觉连贯性需要人工判断。
