# 杠杠の生图机 v0.5.1

## 安装

使用固定标签加载：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.5.1/dist/杠杠の生图机/index.js';
```

## 本次改进

- 出图预设新增「图鉴参考匹配」开关(与「头像参考」互斥):开启后,正文 AI 在 `<pic>` 中声明的"当前出场角色"(如 `当前出场角色：邹峥；`)自动匹配图库文件夹"杠杠の生图机"里 `参考-<标签>-<别名>.png` 命名的文件,按声明顺序附给生图 API;声明缺失或无匹配则不附。
- 出图预设新增「发送同名风格参考图」开关(独立):按预设名精确匹配 `参考-风格-<预设名>.png` 附为画风段。
- 固定段序组装:人物身份 → 画风 → 上一镜头图(未来服装/场景类型在预留槽位扩展);`{{reference_sources}}` 按最终实际发送列表编号,标签如 `图鉴·角色(邹峥)`。
- 改提示词预演列出命中与缺失;审计新增 `reference_match` 与 `matched_count`。
- 默认画图预设指令追加"当前出场角色"声明指令句;已有预设可在画图预设指令中自行添加。

## 使用方法

1. 在酒馆图库"杠杠の生图机"文件夹上传参考图,按 `参考-<标签>-<别名1>,<别名2>.png` 命名(例:`参考-角色-邹峥.png`、`参考-风格-我的预设名.png`)。
2. 在出图预设开启「图鉴参考匹配」(会自动关闭头像参考);需要画风锚定时再开「发送同名风格参考图」。
3. 在画图预设指令中要求正文 AI 输出"当前出场角色"声明(默认模板已自带)。

## 验证范围

- 已验证:目标目录 ESLint 0 问题、`tests/story-image-*` 全部 33 个回归通过、限定范围生产构建;真实酒馆中"声明命中 → 图鉴·角色(邹峥) 与风格段按段序附上"、"partial 语义(声明了无图鉴的 'User')"、"互斥开关"、"物化基准修复后参考图真实附入请求"。
- 匹配对画面质量的实际影响属人工验收范围。

## 已知限制

- 声明制匹配无兜底扫描:正文 AI 未输出"当前出场角色"声明时不附图鉴参考(预演与 toast 会提示)。
- 图鉴文件由用户手动上传命名;别名过短可能误命中,建议别名 ≥2 字符且避免彼此前缀。
- 通过 Tavern Helper `deleteChatMessages` API 删除楼层的限制同 v0.5.0。
