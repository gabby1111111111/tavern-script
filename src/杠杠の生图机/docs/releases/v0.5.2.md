# 杠杠の生图机 v0.5.2

## 安装

使用固定标签加载：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.5.2/dist/杠杠の生图机/index.js';
```

## 本次改进

- 修复：默认画图预设中的"当前出场角色"声明指令句回到正确的默认画图预设（用于教正文 AI），不再误入默认出图预设。
- 修复：恢复镜头或旧镜头重绘时，若 `finalPrompt` 为空或属于恢复的镜头，按当前出图预设模板重新展开最终提示词，避免"两框同文"和风格规则丢失。
- README 补全图鉴使用说明。

## 验证范围

- 已验证：目标目录 ESLint 0 问题、`tests/story-image-*` 全部回归通过、限定范围生产构建。
- 真实酒馆运行时仍需 Gabby 确认：恢复镜头后重绘不再出现两框同文、风格规则丢失；声明指令句位置正确后图鉴匹配行为不变。

## 已知限制

- 声明制匹配无兜底扫描：正文 AI 未输出"当前出场角色"声明时不附图鉴参考（预演与 toast 会提示）。
- 图鉴文件由用户手动上传命名；别名过短可能误命中，建议别名 ≥2 字符且避免彼此前缀。
- 通过 Tavern Helper `deleteChatMessages` API 删除楼层的限制同 v0.5.0。
