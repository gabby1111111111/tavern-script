# 杠杠の生图机 v0.4.4

## 安装

使用固定标签加载：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.4.4/dist/杠杠の生图机/index.js';
```

## 本次改进

- 悬浮面板会记住拖到位置的入口与面板、选择的主题（跟随酒馆／日间／夜色）和图片浏览方式（缩略图／大图）；刷新页面、重载脚本或切换聊天后仍是上次的摆放，不必每次重调。
- 窗口变小、把入口或面板拉回可见范围后，修正后的位置同样会被记住。
- 位置与外观只在拖动松手、主动切换或被位置钳制拉回视口时写入脚本变量，拖动过程不逐帧写入。

## 验证范围

- 已验证：目标目录 ESLint、`tests/story-image-*` 回归测试、限定范围生产构建；真实酒馆中“切换主题 → 刷新 → 保持夜色”闭环、面板位置保持与 `workbenchUi` 脚本变量四字段核验。
- 面板拖动、主题与浏览方式的观感与手感属人工验收，已由 Gabby 在日常使用中确认。

## 已知限制

- 只记忆界面摆放与外观（保存在 Tavern Helper 脚本变量中）；生成图片、候选、确认与任务仍只留在当前页面内存，本版不引入图片持久化。
- 真实生图 API、不同 API 请求模式与最终视觉效果仍需按各自配置单独验收。
