# 杠杠の生图机 v0.3.1

发布日期：2026-09-08

## 安装

公开安装使用固定标签 `杠杠の生图机-v0.3.1`：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.3.1/dist/杠杠の生图机/index.js';
```

## 用户可见变化

- 新增“Swipe 新回答也生图”开关。开启后，只有确实生成了新的 Swipe 回复且该楼层符合出图频率时才请求图片；切换已有 Swipe 不会重复请求，也不会推进 normal 楼层计数。
- API 设置新增质量（低、中、高、自动）和单次生成数量（1–4 张）；同一 `<pic>` 返回多张图片时可逐张查看。
- 同一请求返回的候选图使用图片两侧的左右箭头切换；首尾隐藏对应箭头，不再显示独立的候选页码或横向滚动条。
- 当前图片右下角只显示一组重绘版本页码、上下版本按钮和图片操作；版本切换、候选切换和窄屏布局保持可用。
- 修改提示词窗口先显示场景描述，再显示只读的当前出图模板。模板文本框提高为多行预览，保留头像状态和最终发送提示词预览。
- 修改提示词和区域重绘每次只请求 1 张；当前触发按钮显示转圈加载提示，其他图片操作仍可用。
- “固定”会保留当前版本并清理同楼、同 Swipe、同插图位置的其他候选和重绘版本。进入下一楼时会跨上一楼的全部 Swipe 处理，每个插图位置只保留一张：有手动固定时优先保留固定版，否则保留当时显示的版本。

## 修复

- 删除消息、删除 Swipe 或楼层重排后，图片不会串到其他楼层或候选；已经失效的生成结果也不会重新出现。
- API 档案的空值或越界超时只进行字段级纠正，不再丢弃同档案中的有效地址、模型和 Key。
- 正文清理会保护 Markdown 代码块和行内代码里的 `<pic>` 示例，不会把示例当作真实生图标记。
- 同时返回链接与 Base64 时只保留一个候选，不会重复计数。

## 数据边界

生成图片、参考图、任务和版本只保存在当前页面 JavaScript 内存中。刷新、脚本重载、卸载或切换聊天后不会恢复历史图片；只有用户明确保存到角色图库时才执行持久化上传。
