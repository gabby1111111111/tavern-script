# 杠杠の生图机 v0.4.3

## 安装

使用固定标签加载：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.4.3/dist/杠杠の生图机/index.js';
```

## 本次改进

- 悬浮入口改为相机图标并支持拖动；窗口缩小、切到窄屏或拖过界后，入口与面板会自动回到可见范围，修复“缩小窗口后面板不见了”。
- 面板可以拖动头部移动位置，默认跟随酒馆配色，也可手动切换日间／夜色，并可在“缩略图／大图”之间切换浏览方式。
- 面板头部瘦身：移除说明性提示文字和“X 个镜头 · Y 个任务进行中”汇总行；楼层号变为可点击并跳转到对应正文楼层。
- 正文图片与面板的操作按钮统一为图标（`✎` 修改提示词、`▧` 区域重绘、`✓` 确认、`×` 删除），确认按钮移到删除之后。
- 手机宽度下图片卡片的操作按钮不再单独放大，改为与桌面一致地叠在图片上并整体缩小。

## 验证范围

- 已验证：目标目录 ESLint、目标回归测试、生产构建；真实酒馆中窄视口与矮视口下入口／面板的位置钳制。
- 面板拖动、主题切换、缩略图切换的观感与手感属于人工验收范围，进度以实际使用为准。

## 已知限制

- 面板位置、大小、主题与浏览方式仅保留在本次页面内存，刷新、重载或切换聊天后回到默认。
- 图片、候选与任务仍只在页面内存；本版不增加持久化或刷新恢复。
- 真实生图 API、不同 API 请求模式与最终视觉效果仍需按各自配置单独验收。
