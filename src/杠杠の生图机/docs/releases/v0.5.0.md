# 杠杠の生图机 v0.5.0

## 安装

使用固定标签加载：

```ts
import 'https://testingcf.jsdelivr.net/gh/gabby1111111111/tavern-script@杠杠の生图机-v0.5.0/dist/杠杠の生图机/index.js';
```

## 本次改进

- 点击 ✓ 确认镜头时,该底图自动上传至酒馆图库专用文件夹"杠杠の生图机";同一镜头重绘后再确认走同名覆盖,不产生重复文件。
- 刷新页面、重载脚本或切换聊天后,已确认图自动从服务器恢复到原楼层,确认状态保持;连续剧情的"最近已确认镜头"从此跨刷新可用。
- 删除楼层或已确认插图时,同步删除服务器文件并剪除索引;失败仅警告,不阻塞聊天。
- 审计新增 `storage` 计数,可在酒馆助手机制下核对上传/删除/恢复行为。

## 验证范围

- 已验证:目标目录 ESLint 0 问题、`tests/story-image-*` 全部 30 个回归通过、限定范围生产构建;真实酒馆中"确认 → 服务器文件夹出现身份编码文件 + 索引写入"、"刷新 → 图片从服务器路径恢复回原楼层且确认状态保持"、"原生删除路径(/del 与界面垃圾桶)→ 服务器文件同步删除、索引剪除、孤儿条目一并清理"。
- 面板交互手感与恢复图的显示效果属人工验收范围。

## 已知限制

- 候选、重绘中间版与未确认底图仍只在页面内存,刷新即丢;只有确认过的镜头图进入服务器。
- 通过 Tavern Helper `deleteChatMessages` API 删除楼层不会触发同步清理(酒馆该 API 路径不发出删除事件);界面垃圾桶与 `/del` 命令路径正常。
- 恢复采用"楼层 + Swipe + 图序号"的位置身份:脚本未运行期间发生的删楼,可能让同编号的新回答在刷新后认领旧图;彻底修复需索引 v2 内容指纹,已记录待排期。
- 楼层文本编辑后,会话内确认图消失但索引与服务器文件保留,刷新后该图恢复——此语义待定(剪索引或定义为预期)。
- 真实生图 API、不同请求模式与最终视觉效果仍需按各自配置单独验收。
