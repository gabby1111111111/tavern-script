# 杠杠の生图机 v0.3.0

## 新增

- 画图预设与出图预设分开管理；出图模板使用 `{{xx}}` 接入正文 AI 解析出的图片提示词。
- 出图预设可选择当前 User 与角色头像作为参考图，固定顺序为 User 图 1、角色图 2。
- 最近生成默认保留 10 张，可设置为 1–50 张；每张图片都可删除或保存到角色图库。
- 统一配置正文插图、礼物异步和隔楼触发频率。

## 调整

- 随文图与礼物图统一使用 `{ prompt, referenceImages? }` 请求格式。
- 删除浏览器下载、图片复用、撤回复用、配文编辑、手工三参考图和旧礼物任务。
- 图片仍默认只保存在当前页面内存；只有用户点击“保存到角色图库”时才持久化。

## 修复

- 随文生图期间会在正文对应位置显示“正在生图…”，成功后替换为图片，失败或任务失效时自动清理。

## 升级说明

- v0.2 的多 API 档案、模型、Key、尺寸、超时和额外 JSON 会继续保留。
- 旧随文提示词会迁移为默认画图预设；旧礼物提示词会迁移为兼容预设。
- v0.2 的手工参考图、下载和复用功能不会迁移。
