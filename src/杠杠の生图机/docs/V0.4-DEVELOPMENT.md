## 代码审核修复批次

Gabby 已明确授权子 Agent 修复以下三个 P2。验证证据和临时复现脚本保存在本机临时验收目录，均为模拟请求，不使用真实 API。

| 问题 | 已复现的修前状态 | 修复边界与验收 |
| --- | --- | --- |
| 来源读取失败未降级 | 一个头像路径返回 404，其他两张参考图可用，但生图 POST 为 0 | 在预览/提示词展开之前解析实际可读来源，跳过坏来源并重编号；取消和超时仍终止；提交复用快照不重复读取 |
| 手动取消未结算审计 | 删除前楼参考后重绘停止，runtime 已 ready，但 generation 仍 running | 失效提前退出统一结算 cancelled，保留 generation ID 防串写门控 |
| 容量淘汰回滚未清理占位 | 任务 cancelled 且快照为 0，但 pending host 仍为 1，重渲染后才消失 | 回滚立即清理任务占位，不依赖后续楼层事件 |

结构决策：局部修复，不重写。两项运行时改动由 runtime 子 Agent 独占 `runtime.ts` 与其回归测试；参考读取修复由 prompts 子 Agent 负责 API/来源解析/提示词处理及对应测试，runtime 接入仍由 runtime 子 Agent 单独写入。

参考解析分阶段限定在同一行为链：先抽出已有的单图读取能力，再在来源列表和编辑预览中复用。仅在原请求需要浏览器读取时预读；JSON/Chat 模式可由服务端读取的跨源 HTTP 地址保持原有传递方式。区域重绘的原图和标记图仍是硬输入，不允许缺少一张后降级发送。
