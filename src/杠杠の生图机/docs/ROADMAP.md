# 杠杠の生图机开发路线

## v0.4.0：连续剧情配图（当前版本）

v0.4.0 在 v0.3.1 的逐楼配图上增加按预设组合延续的连续线。它会从当前聊天前面楼层的有效正文插图中选择当前显示版本，并把图片与上一镜头文字作为可选参考；头像参考仍可独立开启。每次生成开始时锁定来源，避免生成中的界面操作改变请求内容。

本版本还支持直接编辑最终 API 提示词、清空提示词、按图片实际记录切换本次参考来源，以及默认无需画笔的整图修改。参考图读取失败会跳过该来源，来源被删除或清理会使依赖任务失效。

## v0.5：更自由的参考来源

后续版本再根据真实使用反馈决定是否增加：

- 用户主动选择某个历史候选、重绘版本或固定场景作为参考；
- 独立的服装、姿势、构图和画风参考槽；
- 参考来源排序、数量限制和不同 API 能力的提示；
- 更适合异步聊天的最近生成与候选管理。

这些方向不改变 v0.4.0 的页面内存边界，也不会在没有实际需求前增加自动重试、持久化图片或后台队列。

## 验收原则

纯代码测试、ESLint 和构建只覆盖可重复的代码行为。真实 API 模式、正文事件时序、图片参考传递、页面展现和视觉连贯性需要在实际 SillyTavern 配置中单独验收。
