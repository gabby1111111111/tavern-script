# Changelog

本文件只记录“杠杠の配音室 · 内置远程音效库版”的用户可见变化。

## [Unreleased]

## [0.1.0] - 2026-09-09

### Added

- 在共享配音、朗读和自定义音效能力上增加可直接读取的远程 SFX/Ambience 目录。
- 目录版本固定为 revision `f800e5e4f23508b3336d63a7274f4108b84e30c1`。
- 目录只留在页面内存；音频在试听或播放时按需请求，不打包进 JavaScript 制品。
- 为 Edition、目录数量和播放时间线提供小型 Audit 证据。

### Security

- AI 音效计划只接收音效 ID、名称、分类和说明，不接收音频 URL 或任何 API Key。
- 运行时不读取移动分支，也不把远程目录或音频写入 Tavern Helper 设置。

### Distribution

- 功能版本：`0.1.0`
- 与纯自定义音效版共用 Tag：`杠杠の配音室-v0.1.0`
- 预览制品：`dist/杠杠の配音室-内置远程音效库/index.js`
- 本次与纯自定义版一起上传，但必须在附件名和 Release Notes 中标明“预览”。
- 本次上传不构成素材授权，也不自动批准后续版本继续附带本 Edition。
