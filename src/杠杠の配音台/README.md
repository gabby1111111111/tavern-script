# 杠杠の配音台 · 纯自定义音效版

一个面向 Tavern
Helper 的轻量配音脚本：配置多个 TTS 来源，让当前酒馆 AI 自动生成角色配音表，并从消息、单句、选中文字或最近语音直接播放。

> 当前版本：`v0.1.0`。这是首版默认推荐制品，只提供用户自行配置的音效。

## 第一版能力

- Edge、OpenAI-compatible、豆包、MiniMax、小米 MiMo Provider Profile。
- AI 读取当前角色卡、设置范围内最近聊天和音色目录，生成主要角色配音表。
- 全文、仅对白、指定角色、单一音色、选中文字五种朗读方式。
- 最近十条语音：播放/暂停、重新生成、下载；刷新后列表消失。
- 原文旁对白按钮和真实准备/播放/暂停状态。
- 自定义短音效与环境音、AI Cue、原文旁音效按钮。
- 整段朗读自动插入短 SFX，严格执行“台词 → 音效 → 台词”；Ambience 独立试听。
- Stop、换聊天、重抽、编辑、删除和卸载会取消旧任务。

## 安装与最短使用流程

1. 在 Tavern Helper 中加载固定版本的 `dist/杠杠の配音台/index.js`。不要直接依赖持续变化的 `main` 分支。
2. 打开面板，新增或选择 TTS Profile，填写服务配置。
3. 点击检查并读取音色。
4. 点击“一键 AI 配音表”。
5. 选择朗读方式，朗读最新消息或使用消息旁按钮。
6. 若要音效，在“自定义音效”中填写有权使用且浏览器可访问的音频 URL、名称、分类和说明，先试听，再点击“AI 配最新音效”。

Tavern Helper loader 应固定到 `杠杠の配音台-v0.1.0`
Tag 下的上述 dist 路径。切换 loader 前先备份自己的 Profile 与 Key；不要分享包含脚本变量的导出物。

## Provider 与依赖

| Provider          | 额外依赖或限制                                                          |
| ----------------- | ----------------------------------------------------------------------- |
| Edge              | 外部 Edge TTS 插件；本项目不内置                                        |
| OpenAI-compatible | 对应服务需允许浏览器请求                                                |
| MiniMax           | 受服务 API/CORS 规则约束                                                |
| 小米 MiMo         | 配置探针不等于真实联网合成                                              |
| 豆包              | 安装 `server-plugins/ganggang-tts-bridge` 并重启正确的 SillyTavern 实例 |

豆包 bridge 只代理固定豆包 TTS 能力，不是通用代理。

## 自定义音效

- 每条音效可填写名称、短音效/环境音、分类、音频 URL、给 AI 的简短说明和试听音量。
- 短音效可以插入整段朗读；环境音只独立试听，不阻塞台词队列。
- 音频 URL 必须使用浏览器可直接访问的 `http://` 或 `https://` 地址，并可能受到 CORS、鉴权、防盗链和重定向影响。
- 设置中只保存音效元数据和 URL，不保存音频 Blob、Base64 或下载副本。
- 使用者负责确认自己添加的音频及其托管方式具备相应使用权限。

## 隐私与存储

- AI 配音表只在明确点击后发送当前角色卡、设置数量内的最近聊天和可用音色目录。
- AI 音效计划只在明确点击后发送当前消息、可朗读片段以及音效 ID、名称、分类和说明；音频 URL 不发送给酒馆 AI。
- API Key 不发送给酒馆 AI，也不得进入 Audit、缓存描述或日志。
- Profile、凭据、配音表和自定义音效元数据保存在 Tavern Helper 脚本变量中。
- 最近十条只在页面内存；合成缓存使用当前浏览器 origin 的内存与 IndexedDB。
- MiniMax 音色查询结果只保留在页面内存。

## 常见问题

### 点击播放没有声音

先检查浏览器自动播放限制，再检查 Profile 与音色。可只读查看 `window.__ganggangVoiceAudit`，但不要公开完整设置。

### 自定义音效能试听，AI 却没有放置按钮

确认音效已启用，并填写能区分场景的名称、分类和简短说明。AI 只能从这些元数据中选择，不会读取音频 URL 或试听音频内容。

### 豆包 bridge 不可用

确认 companion 位于目标 SillyTavern 的 server plugin 目录并重启了正确实例。

### 为什么最近十条刷新后没了，但第二次生成仍可能更快？

最近十条是页内操作历史；合成缓存是独立 IndexedDB 层。

### 为什么 Ambience 不自动卡在台词中间？

长环境音会阻塞串行朗读，所以第一版只自动插入短 SFX。

## 开发与验收

维护入口、事件路线和故障索引见 [AGENTS.md](./AGENTS.md)。用户可见变更见 [CHANGELOG.md](./CHANGELOG.md)。

发布前必须使用生产构建或 CI bundle，并对最终制品重新完成 8000 实机验收。项目许可证以仓库最终确认的发布声明为准。
