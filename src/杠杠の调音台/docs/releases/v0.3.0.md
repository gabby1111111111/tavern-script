# 杠杠の调音台 v0.3.0

发布日期：2026-09-09

## 新功能

- 可以建立、保存、删除并切换多套提示词方案。
- 可以设置“隔几楼出歌”；`0` 表示每个新正常 AI 回复都发送出歌提示。
- 可以选择新 Swipe 回答是否尝试出歌，Swipe 不会改变正常楼层计数。
- 设置抽屉会直接显示“杠杠の调音台 v0.3.0”。

## 改进与修复

- 旧版提示词会安全迁移为默认方案，不会静默丢失。
- 播放列表与候选数量统一限制为 1–20。
- 加强生成事件的单次结算、停止处理和运行时审计。
- 加强网易云歌单、Bilibili 环境音的取消、超时和过期请求隔离。

## 已知限制

- “Swipe 新回答也出歌”在部分运行时事件顺序下仍可能偶发不触发。推荐默认关闭或在需要时手动开启；这不会影响正常正文楼的出歌间隔。
- 在线音频仍依赖第三方音乐接口、网络代理和浏览器自动播放权限。

## 升级

- 保留旧的 `dist/杠杠の调音台/index.js` 安装路径，原有脚本变量设置可继续使用。
- 更新固定版本导入标签为 `杠杠の调音台-v0.3.0`。
