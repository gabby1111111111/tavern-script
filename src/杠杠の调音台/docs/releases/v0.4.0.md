# 杠杠の调音台 v0.4.0

移除环境音模块。BGM 功能不受影响。

## 为什么要移除

B 站取播放地址的接口已不再返回音频：

```
types=search&source=bilibili   → 仍能返回 BV 号（可用）
types=url&source=bilibili      → 恒为 { "url": "", "br": -1, "size": 0 }
```

也就是说环境音能搜到条目，但拿不到任何可播放的音频。v0.3.2 已将其标记为闲置，
本版本把相关代码、设置项和界面一并删除，避免每轮都产生一次注定失败的请求。

同一轮探测中，BGM 侧 netease 可播率 46/48（96%），
joox 与 bilibili 均为 0/48——B 站并不是"部分不可用"，而是整条取地址链路不可用。

## 删除范围

| 位置 | 内容 |
| --- | --- |
| `ambient-audio.ts` | 整个文件删除（B 站搜索、BV 号解析、备用 BV 号兜底） |
| `index.ts` | 环境音标记扫描、`<杠杠-环境音>` 日志、状态变量、运行时函数（共 190+ 行）、审计 `ambient` 字段、提示词环境音段 |
| `bgm-settings.ts` | `module_enabled.ambient`、`ambient_prompt_content`、`ambient_fallback_bv_ids`、`DEFAULT_AMBIENT_PROMPT_CONTENT` |
| `BgmSettings.vue` | “环境音”标签页、启用开关、“环境音要求”提示词、“环境音保底 BV 号”输入框 |

### 界面变化

设置抽屉的标签页由 4 个减为 3 个：

```
v0.3.2:  BGM / 环境音 / 提示词 / 更多
v0.4.0:  BGM / 提示词 / 更多
```

### 提示词占位符

不再提供 `{{current_ambient_location}}` 与 `{{current_ambient_title}}`。
自定义提示词模板里若仍写着这两个占位符，只会原样保留，不会被替换。

### 运行时审计

`window.__ganggangConsoleAudit` 不再包含 `ambient` 字段。
其余字段（`run_id`、`generation`、`prompt_injection`、`playlist_prompt`、`marker`、
`stream_finished`、`music_lookup`、`playlist`、`audio_played`、`last_error`）不变。

## 迁移说明

- 已有的环境音设置会被忽略，不影响 BGM 读取设置；无需手动清理。
- **如需日后恢复环境音**：完整实现保留在 tag `杠杠の调音台-v0.3.2`
  （该版本保留逻辑，仅标记为闲置）。找到可用音源后可从该 tag 取回
  `ambient-audio.ts` 及 `index.ts` 中的环境音链路，无需重写。
